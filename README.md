# Ainx AI — Ainfilms CRM

A lightweight, responsive CRM for Ainfilms built as a static web app with persistent browser storage.

## Included
- Dashboard with pipeline KPIs
- Lead database and stages
- Pipeline board
- Contacts
- Outreach message generator
- Proposal tracker
- Project tracker
- Tasks
- Analytics
- Service presets
- Ainx Agent rule-based sales copilot
- Responsive desktop/mobile UI

## Deploy
This repository includes a GitHub Pages workflow in `.github/workflows/pages.yml`.

To publish with GitHub Pages, open repository **Settings → Pages** and set **Source** to **GitHub Actions**. Then run the workflow or push to `main`.

Expected public URL after Pages is enabled:

`https://ullaspmuraliofficial-design.github.io/AFS/`
